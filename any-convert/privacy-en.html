AnyConvert Privacy Policy

Last updated: 2026-11-12

Five promises: no uploads, no network capability, no personal data, local-only reads and writes, nothing leaves the device.

1. What we process

  • Files you pick: read on this device only after you press Start, solely to produce the result.
  • Conversion history: source name, target format, size, time and failure reason. At most 100 rows, clearable at any time.
  • Diagnostic log: local-only error time, error code, file type and size (no file contents, no full paths). At most 500 entries, oldest overwritten, never uploaded.
  • Settings: theme, language, output location, naming rule and conflict policy, stored locally only.

2. Your files never leave the device

Format detection, decoding, encoding, composition and packing all run on your device. There is no server and no upload endpoint.

This app does not request the INTERNET permission. You can verify it in the system app-permission screen: no network entry is listed.

This app makes no network request at all; the system privacy report can verify it. iOS has no network-permission switch, so we rely on the privacy report and the code itself rather than a permission declaration.

3. No personal data collection

  • No accounts and no sign-in.
  • No analytics, crash-reporting or advertising SDKs.
  • No access to contacts, location, clipboard or device identifiers.

4. Minimal permissions

  • Files are picked with the system picker; no storage permission is requested.
  • The add-only photo permission is requested only when saving to the album; album content is never read.
  • If the album write fails you can save into the app documents folder instead.

5. Results and metadata

Conversions strip EXIF metadata, including location. Output is written only where you choose, and source files are never overwritten.

6. Your control

  • Clear cache: removes temp files and thumbnails, keeps history and settings.
  • Clear history: removes history rows, keeps converted files.
  • Uninstall: removes local settings, history and files inside the app folder.

7. Contact

The app is fully offline and has no network contact channel. Please use the developer contact listed on the store page.
